This script is a desktop GUI tool that turns an entire YouTube channel, playlist or other source into audio fingerprints (pklz files) automatically. It chains together the whole process of downloading, preprocessing, and fingerprinting, into one window with a Start button, instead of running yt-dlp commands, bat scripts, and managing folder structures by hand.
